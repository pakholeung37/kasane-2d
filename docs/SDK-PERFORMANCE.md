# SDK 内存编辑初步测量

命令：`cargo run --release -p kasane-sdk --locked --example checkpoint_profile`。2026-09-23 于 Darwin arm64、rustc 1.98.1 测得；每组由一张合成资源描述和指定数量的四顶点 mesh 构成，不读取纹理。候选构造时间取 20 次均值，其它时间为单次观测。

| mesh 数 | 内容估算字节 | 候选构造均值 | 全结构校验 | metadata edit（含候选与校验） | 一条历史的估算字节 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 8 | 8,811 | 6 µs | 19 µs | 47 µs | 9,758 |
| 512 | 463,293 | 209 µs | 2,697 µs | 3,459 µs | 464,240 |

估算包含持久内容的集合与数组 capacity，不是进程 RSS。默认 history 上限仍为 50 步、256 MiB；这些合成模型只建立早期比较口径，不能推断复杂导入工程、GPU 或 Python 的开销。完整 S5 性能验收需用真实大模型及相同 workload 重测。
