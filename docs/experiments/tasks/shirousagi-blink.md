# 从 Shirousagi 分层 PSD 创作双眼眨眼

`input/project/` 是从真实 Shirousagi PSD 导入的可编辑静态工程；
`input/Shirousagi.psd` 是原始 24 层素材。`input/references.json` 列出交付模型的
参考帧及参数值。你拿不到原 rig。请使用公开 `kasane` API，让两只眼睛能**独立**
眨眼：`ParamEyeLOpen` 和 `ParamEyeROpen` 都是普通参数，范围 `[0,1]`、默认 `1`，
`0` 为闭眼。创建参数时指定相同的运行时 ID，使导出的 model3/MOC3 可按这些 ID
驱动。两眼同时闭合、只闭一眼和任意中间值都应自然；参考帧中的耳朵和身体动态
不属于本题，只比较眼部区域。非眼部应保留 PSD 原有画面。

保留 24 个图层、素材内容与隐藏状态；只给现有眼部图层添加必要的可编辑绑定，
不要修改 `input/`、PSD 或 PNG 素材。参考帧用于观察目标，不可作为纹理替换进工程。
不要读取主持人目录、源仓库或其他受试任务。

交付：

- `solution.py --output <绝对目录>`，从脚本所在目录寻找 `input/`，在新的空输出目录
  可重放。先在任务包的 `output/` 实际运行。
- 输出根内保存的可编辑工程、可搬迁 model3/MOC3/纹理 package。
- 输出根或交付子目录内的 `result.json`，包含实际绝对路径 `project_manifest` 和
  `package_model3`。如有多份，主持人读取最新写入的一份。
- `notes.md`：说明选中的图层、关键形态设计、公开和自选组合姿态验证、遇到的错误
  及恢复、依赖用途和仍有的不确定性。

主持人会重开工程和 package，复制到新目录，检查全部原图层与资产、两参数运行时
身份、公开与未公开的中间值/组合姿态、非眼部画面和空目录重放。
