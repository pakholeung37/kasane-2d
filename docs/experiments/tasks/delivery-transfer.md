# S3-A：修改模型并交付可搬迁的模型包

这是待生成任务包的公开任务模板。发放时主持人提供完整 input、request.json、
公开 SDK 文档、共享 Python 的绝对路径和 20 分钟运行预算；未提供这些材料时不启动。

请导入 `input/model.model3.json`，按 `input/request.json` 中的目标 mesh、参数、
关键形态、坐标空间与位移量进行局部修改。其他对象、参数、关键形态和纹理内容
必须保持。任务只涉及几何、参数和纹理，不要求新增物理或动作文件。

交付一个可重新打开的 Kasane 工程，以及从修改后的工程导出的 model3/MOC3/纹理包。
两者必须能复制到别的目录后独立使用，不依赖原输入目录或你的临时文件。
在同一输出根再次执行也应成功，不破坏先前正确作品；可以复用正确产物或新建子目录。

请提交：

- `solution.py --output <绝对目录>`，以及需要的辅助文件。输入从脚本所在任务目录寻找。
- 在传入输出目录创建工程与导出包，并写 `result.json`，包含 `project_manifest` 和
  `package_model3` 的实际绝对路径。二者必须位于该输出根内，子目录和文件名可自选。
- `result.json` 可放在输出根目录，或每次交付的子目录中；如有多份，主持人读取最新写入的
  一份。再次运行须保留之前已交付的工程和包。
- `notes.md`：写明验证方式、遇到的错误、恢复方法和安装的依赖用途。

请实际执行脚本，并验证默认值、参数中点和目标端点的结果。数值绝对容差为 `1e-6`；
保存造成的资源路径变化、会话版本变化不要求保持；重新导入导出包后允许生成新的
authoring UUID，但模型语义应一致。

使用公开 kasane API 修改工程，不直接编辑工程 JSON/MOC3，不修改 input 或文档。
可读取 model3 的公开引用及 PNG 信息，可安装依赖：
`uv pip install --python <本轮共享Python> <包名>`。不需要创建新的环境或独立锁文件。
不得替换被测 SDK，也不要读取主持人的预期结果、其他受试目录或仓库实现。
