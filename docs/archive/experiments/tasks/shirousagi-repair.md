# 真实模型组合姿态返修

`input/project/` 是可编辑的 Shirousagi 工程，`input/Shirousagi.psd` 是其分层美术素材。
模型在默认姿态看起来正常；在 `input/references.json` 所列的转头与表情组合中，
局部图层出现明显错位。参考 PNG 是交付前应有的画面。请自行定位原因，只修复
必要的 authoring 状态。PSD 是静态分层美术依据；它不包含原模型的动态 rig。

你可以用公开 `kasane` API 检查工程结构、求值、观察和编辑，也可以用普通图像库
分析参考图。请保留现有 mesh、参数、变形器、绑定和资源的身份与其他行为。
不要修改 `input/`、纹理或 PSD，也不要通过替换参考 PNG 或只输出渲染图交付。
不要读取主持人目录、源仓库或其他受试任务。
如需安装图像依赖，使用 `uv pip install --python <本轮共享 Python> <包名>`，
在 `notes.md` 说明用途。

交付：

- `solution.py --output <绝对目录>`，从脚本所在目录寻找 `input/`，可在新的空输出
  目录重放。先在任务包的 `output/` 实际运行。
- 输出根内保存的可编辑工程及导出的可搬迁 model3/MOC3/纹理 package。
- 输出根或交付子目录内的 `result.json`，包含实际绝对路径 `project_manifest` 和
  `package_model3`。如有多份，主持人读取最新写入的一份。
- `notes.md`：说明定位依据、修改范围、公开与自选姿态的验证、遇到的错误及恢复、
  依赖用途和仍有的不确定性。

主持人会重新打开工程与 package，复制到新目录，检查已公开及未公开的参数组合、
非目标对象状态和资源完整性，再在空目录重跑脚本。请勿依赖输出目录已有文件。
