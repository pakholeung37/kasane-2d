# M3：MOC3 导入、编辑与再导出

状态：待实施，未验收。依赖：M1、M2。返回 [总路线图](../ROADMAP.md)。

## 1. 交付结果

将本轮支持范围内的外部 MOC3 转换为 Document，修改网格、变形器和参数形态，保存重开，再导出有效 MOC3。导入之后无需原始 MOC3 即可继续编辑和导出。

## 2. 输入与输出

- 输入方式一：`model3.json` 及其引用的 MOC3、纹理。
- 输入方式二：直接选择 `.moc3`，另行提供纹理槽到图片的映射。不能从裸 MOC3 猜测图片路径。
- 接受的模型文件：`csmMocVersion_33` 与 `csmMocVersion_50` 小端文件，且使用总路线图列出的语义集合；版本受支持不代表可以跳过特性检查。
- 输出：独立 Document、可由 M2 保存的素材引用、导入诊断和源对象到 Document ID 的映射。

运行包中的 motion、expression、physics 文件不转换为编辑数据，也不在再导出时声称已经保留；导入报告列出这些未导入的附件。模型内部不支持的语义则拒绝整个可编辑导入，不能默默扁平化。

## 3. 映射要求

| MOC3 信息 | Document 要求 |
|---|---|
| 画布、原点、单位 | 明确转换并保存，重导出保持一致 |
| ID、Part、父链接 | 保留运行时 ID，生成稳定内部 ID，重建组织与变形关系 |
| Mesh、纹理槽、UV、索引 | 恢复可编辑几何；生成顶点 ID，映射覆盖全部 Keyform |
| Rotation / Warp | 恢复类型、父关系、基础属性和全部形态，不能把变形结果烘焙为当前帧顶点 |
| 参数与绑定 | 保留范围、默认值、轴顺序、关键值和组合形态 |
| 绘制属性 | 顺序、透明度、颜色、混合、普通/反向遮罩对应稳定引用 |

基于 M1/M3 共用的文件解码层读取源表，复用 PurismCore 的格式校验；仅通过运行时 drawable 输出不足以完成导入。文件偏移和临时指针不进入 Document。

两种版本分别映射到同一 Document。旧版本没有的颜色字段使用对应运行时默认值，映射说明和测试必须覆盖；再次导出统一生成 M1 的 5.0 文件，不要求保持原输入文件版本。

文件未提供的显示名称可由运行时 ID 初始化，顶点 ID 由导入器生成，报告注明这些生成字段。不宣称恢复 Cubism 原工程的编辑历史或未读取到的元数据。

基础形态与 Keyform 的映射必须显式定义：有绑定的对象保留每个关键组合的完整形态；默认参数的求值结果不能冒充全部 Keyform。没有独立文件字段对应的编辑基础数据采用确定性初始化规则，并由往返对照证明不改变运行结果。

## 4. 实施步骤

1. 文件检查器先列出版本、section、对象计数和特性，拒绝超出版本或特性集合的输入。报告到具体类型和对象，不能统一报“导入失败”。
2. 解析到独立、已校验的数据视图，建立 ID 和引用映射。
3. 在候选 Document 中依次创建素材槽、Part、变形器、Mesh、参数、绑定和全部 Keyform，再连接关系并验证。
4. 按统一参数集比较原模型运行输出与候选 Document 求值；测试失败时修正映射，不用截图相似替代源结构完整性。
5. 导入成功后替换应用当前文档；结构或特性检查失败保留原文档。缺图片按 M2 的资源不完整状态处理，不冒充完整导入。
6. 从导入 Document 重新生成 MOC3，对照原模型；修改后再次生成，验证编辑确实进入输出。

## 5. 验收

遵守 [统一验收规则](../VALIDATION.md)。

| 用例 | 必须验证 |
|---|---|
| M1 构造模型往返 | 全部本轮字段保留，按 ID 对齐后的模型与运行结果一致 |
| 独立外部模型 | 两个接受版本各至少一份不是本项目导出器生成、且特性在范围内的模型；用例集合必须含参数、Keyform 和嵌套变形 |
| 导入后修改 | 分别修改 Mesh Keyform、Warp 控制点、Rotation 形态、参数绑定、绘制属性，再导出看到对应变化 |
| 结构编辑 | 新建 Mesh 和参数、重绑定、删除已解绑对象，再导出有效模型 |
| 脱离原文件 | 保存工程后移走原 MOC3 和原纹理目录，仅靠工程可重开、修改、导出 |
| 资源映射 | 裸 MOC3 与 model3 两种入口；多纹理槽正确，缺图不使用猜测路径 |
| 不支持内容 | 未知版本、BlendShape、Glue、Offscreen、循环参数明确拒绝，不提交部分 Document |
| 坏文件 | 越界、截断、非法数量、错误引用不崩溃，不改当前工程 |

导入与未修改再导出比较语义，不要求字节完全相同。外部模型必须独立验证，不能仅用自己的 writer 与 reader 相互通过来证明兼容。
